# VideoFrame Pro — 视频截帧 · AI 挑帧 · 拼图出图

## 项目概述
- **名称**: VideoFrame Pro
- **目标**: 在浏览器端从视频按间隔/场景截取关键帧，调用 Vision AI 智能挑选最佳画面，并拼接导出为多宫格成品图。全程本地处理，隐私安全。
- **核心特性**: 视频截帧、AI 智能挑帧（Vision 大模型 + 本地算法降级）、AI 审美记忆、拼图批次填充与导出、4 套主题、撤销/重做、键盘快捷键。

## 技术栈
- Hono + Cloudflare Pages（Vite 构建）
- 单文件前端应用 `public/app.html`（通过 `?raw` 注入 `src/index.tsx`）
- 原生 Canvas 截帧、IndexedDB 审美记忆、Web Crypto/Fetch
- 设计系统：CSS 自定义属性（`[data-theme]` × `[data-mode]`）

### ✅ Batch 3 — 智能截帧与编辑（已完成）
- **场景检测截帧**：截帧参数面板可切换「固定间隔 / 场景检测」。场景模式以细粒度探针扫描视频，对相邻帧在 32×18 缩略图上做像素差分，差异超过灵敏度阈值且满足最小间隔时保留关键帧。灵敏度滑块（低 / 中 / 高 / 极高）。
- **单元格裁剪编辑**：拼图每个已填充格子悬停显示裁剪按钮，弹窗内可拖动调整画面位置 + 滚轮/滑块缩放（1~3×），九宫格参考线，复位/取消/应用。裁剪结果同步到缩略图与最终出图，并纳入撤销/重做。
- **AI 逐帧评分可视化**：AI 挑帧后，每帧缩略图底部显示评分条 + 数值徽章（Vision 显示综合分 1~10，本地显示相对百分比），按相对分高低呈翠绿/青/琥珀渐变，悬停查看清晰度/构图/吸引等明细。

### ✅ Batch 4 — 批量与导出（已完成）

- **导出选项**：「导出选项」弹窗可设置格式（JPEG / PNG / WEBP）、质量（PNG 自动隐藏质量项）、分辨率倍率（0.5× / 原始 1× / 2×，以源帧分辨率为基准缩放）。设置应用于单批次与一键下载全部。**不含 ZIP 打包**（逐文件下载）。

- **生成后不再强制弹全屏**：拼图生成完毕保留在工作区，点击预览缩略图按需全屏（全屏内可点格子替换/裁剪/清空）。
- **挑帧引擎透明化**：AI 挑帧后明确告知实际使用的引擎与模型，三处持久展示——

  - 区分「🤖 Vision AI（含模型名，已生效）」「⚙️ 本地算法（未配置 AI Key）」「⚠️ Vision 调用失败已降级本地算法（附真实失败原因，如 401 无效令牌 / 余额不足 / 网络错误）」「❌ 挑帧失败（附原因）」；

### ✅ 意图驱动的挑图 / 评分 / 拼图位置优化（已完成）
目标：让最终拼图**代表整个视频**——四宫格主打「展现主题、吸引点击」（封面思维），九宫格主打「强化主体、展示细节」（细节叙事思维）。

- **挑图意图选择器**：AI 面板新增「封面四宫格 / 细节九宫格 / 自动」三态切换（`#aiIntentSeg`）。`auto` 会依据当前拼图批次智能推断（≥9 格→细节，≤4 格→封面）。切换意图时自动建议推荐帧数（封面 8 / 细节 12，用户手动改过则不覆盖）。
- **7 维评分体系**（原仅 4 维）：在「清晰度 / 构图 / 吸引力 / 综合」基础上新增——
  - **主题代表性 theme**：该帧是否能概括整段视频的主题；
  - **主体突出 subject**：画面主体是否清晰突出、占比合理；
  - **细节量 detail**：纹理 / 内容信息密度。
  Vision 提示词按当前意图注入「本次目标」（封面 / 细节），并要求模型按 7 维打分；解析时对缺失维度做合理回退（theme→overall、subject→构图、detail→清晰度）。
- **意图加权合成**：不同意图使用不同维度权重——封面侧重 `吸引+主题+构图`，细节侧重 `主体+细节+清晰`；综合分 = 综合×0.30 + 意图加权×0.62 + 个人审美微调×0.08。本地降级算法同样按意图把 7 维近似映射到锐度/饱和/亮度特征。
- **时间覆盖（代表整段视频）**：贪心多样性挑帧（`greedyDiversePick`）新增时间覆盖因子，把帧的时间位置归一化后纳入综合评分，使被选帧尽量铺满视频开头到结尾，避免全部挤在某一段。
- **意图感知的拼图位置**（`placeFramesIntoBatch`）：
  - **细节九宫格**：最强主体帧放**正中 C 位**，其余 8 张按**时间先后**环绕排列，形成「主体居中 + 叙事顺序」；
  - **封面四宫格**：最强帧放**左上黄金位**，其余按视觉权重次序铺开，第一眼抓住注意力。
- 帧评分浮层与「挑帧引擎」卡片同步展示新维度（综合/主题/主体/细节/清晰/构图/吸引）与当前挑图策略标签。

### ✅ 标准自动化 · 美学强化 · 千问默认（已完成）
根据用户反馈进一步打磨：四宫格与九宫格用**不同标准自动挑图**（无需手动选），并强化构图/画面美观度，默认模型切换为最新通义千问。

- **挑图标准全自动（移除手动选择器）**：不再让用户选意图。每次输出都同时产出四宫格与九宫格——**四宫格自动按「封面」标准、九宫格自动按「细节」标准**，由 `batchIntentKey(b)` 依批次尺寸判定（≤4→封面，≥9→细节）。AI 面板原选择器替换为只读说明面板。
- **同批评分、逐批次各取所需**：一次 Vision 评分得到全部帧的 7 维分数后，`selectFramesForIntent(scores, count, pixCache, intentKey)` 会为每个批次**用其自身意图权重重新加权排序**再挑选。实测四宫格挑出「构图/美观」高的帧、九宫格挑出「主体/细节」高的帧，两者**选帧零重叠**，真正差异化。
- **强化构图 + 画面美观度**（用户重点要求）：封面权重提升 `构图0.26 + 美观0.26`（合计 0.52 为主导）；细节也把构图提到 0.18 并保留美观 0.11。Vision 提示词对 composition（三分法/黄金分割/留白/视觉引导线/层次）与 appeal（色彩和谐/光影质感/整体美感）做了更细的描述。
- **默认模型 = 通义千问**：模型下拉默认选 `qwen3-vl-plus`（兼顾速度与效果）；GPT/Claude 仍保留备选。

### ✅ 模型列表校准 · 视频关闭 · 只看已选（已完成）
- **千问模型列表按 API 实际支持校准**：核对接口 `/v1/models` 返回的真实可用视觉理解（VL）模型，移除了接口并不提供 VL 版本的型号（如 `qwen3-vl-235b`、`qwen3.5-plus`，避免调用即报错），保留并实测可用：`qwen3-vl-plus`(默认)、`qwen3-vl-plus-2025-12-19/0923`、`qwen3-vl-flash` 系列、`qwen-vl-max/plus` 系列、`qwen2.5-vl-32b`。默认 `qwen3-vl-plus` 已用真实图片验证可正确识别画面内容。
- **视频关闭 / 更换**：视频预览区新增「关闭/更换视频」按钮（`closeCurrentVideo()`），上传错误时可一键移除当前视频（含其帧与拼图，带确认）后重新上传；并重置文件选择框，支持再次选择同一文件。删除项目逻辑抽出 `deleteProjectNoConfirm()` 复用。
- **只看已选**：帧墙工具栏新增「只看已选」开关（`toggleOnlySelected()` + `S.onlySelected`），开启后帧墙仅显示 AI/手动选中的帧、隐藏其余，方便聚焦查看挑图结果；再次点击恢复全部。重新截帧或切换项目时自动退出该模式。

## 主要交互入口
- 工作区切换：左侧导航 / 快捷键 `1` `2` `3` / `switchTab(idx)`
- 截帧：截帧参数面板「截取视频帧」，或「一键截帧 · AI挑帧 · 出图」
- AI 挑帧：AI 面板「AI 自动挑帧」/「挑帧并自动填入所有批次」；挑图标准按拼图类型自动套用（四宫格封面 / 九宫格细节，无需手动选）
- 拼图：拼图面板添加批次（2×2 / 3×3 / 自定义）→ 填充 → 一键生成 / 下载

## 数据架构
- **运行时状态** `S`：`frames`（截取帧 `{dataUrl,time,idx,w,h}`）、`selected`（已选）、`batches`（拼图批次，`cells` 存帧索引）、`aiScores`、`imgCache`、`aiIntent`（封面/细节/自动）、`lastIntentKey`、`lastPick`（挑帧引擎透明化记录）
- **意图预设** `INTENT_PRESETS`：cover / detail / auto，各含 7 维 `weights`、`coverage`（时间覆盖强度）、`qualityVsDiversity`、`promptGoal`（注入 Vision 提示词的目标描述）
- **历史栈** `HISTORY`：`stack` / `future`，存储 `batches[].cells` 深拷贝快照
- **持久化**：IndexedDB（AI 审美记忆 good/bad 参考图）、localStorage（API Key、主题）
- **存储服务**：纯前端，无后端数据库；后端仅 Hono 提供静态资源与页面
