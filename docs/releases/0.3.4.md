# 帧选 0.3.4 · 16:9 自定义裁剪与 AI 连接改进

- 单图、四宫格封面都支持「原比例 / 16:9」输出，不限制源视频或图片比例。
- 点击「调整裁剪」可拖动取景、缩放；四宫格可逐格调整，切换格子自动应用当前裁剪。
- 修复宽画面在 100% 缩放时无法左右拖动的问题，编辑预览和下载使用同一套裁剪计算。
- 版式与比例分别记住裁剪，支持撤销、重做和历史恢复；下载及 ZIP 保留 16:9 与 4K 角标。
- 桌面端 AI 请求改为原生网络通道，支持系统代理、超时与取消；暂停、停止或移除运行任务会取消请求。
- 将含糊的 Failed to fetch 改为可操作的连接提示；区分密钥无效、权限、限流、请求过大及模型服务故障。

## 使用方式

生成结果 → 封面选择「单图」或「四宫格」→ 输出比例选「16:9」→「调整裁剪」→ 拖动或缩放 → 应用 → 下载。

AI 评分仅发送最长边 480 像素的压缩代表帧；21:9 或 4K 不会导致原视频上传。若连接仍失败，请按新版显示的具体提示检查网络、代理或接口账号，也可切换本地选图完成制作。

更新：设置 → 版本与更新 → 检查更新 → 保存并安装。
