## 更新与使用

设置 → 版本与更新 → 检查更新 → 保存并安装。打开生成结果或已有历史任务，在封面版式中选择「单图」，点击画面替换，开启 4K 角标后下载；无需重新截帧或评分。

0.2.0 及更新版本支持应用内更新；0.1.6 及更早版本需手动安装一次。更新通道已开放，不代表用户电脑已安装。

交互与成图测试在 Chromium 中完成；Windows 另行验证了原生模块、安装和启动，未将这些浏览器用例描述为 Windows WebView 实机交互。仓库下载入口更新不代表另行部署了 Cloudflare 网站。发布后的说明提交不改变发行标签或安装包。
