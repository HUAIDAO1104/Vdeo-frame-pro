# 帧选 0.3.6 · 8:9 渐变竖图与可调投影

- 竖屏拼图固定为 8:9，默认六张、3 列 × 2 行，输出 1600×1800；不再紧密铺满，也不再提供其他竖屏整体比例。
- 每格保持竖向取景，图片之间留有间隙，周围保留外边距；末行不足时居中排列。仍可调整张数与列数。
- 从当前选中的图片提取两种代表颜色，生成对角渐变背景。取色全部在本机完成，不调用 AI；未选中的候选不影响背景。
- 替换或移除图片后自动更新背景；预览、下载、ZIP 和历史恢复保留同样的间隙与渐变。
- 每张竖图增加柔和的立体投影，可在生成前或结果卡片中统一调节投影大小与距离。默认大小 24、距离 12；设置支持撤销、重做和历史恢复，下载保留相同效果。
- 启动默认使用 16:9 横屏四宫格，并生成详情长图；上次临时使用竖屏模式不会改变这一启动默认。
- 主动选择竖屏拼图时仍默认关闭详情长图，需要时可以手动开启。原有逐格裁剪、交换、角标、撤销和历史功能保留。

## 使用方式

常规横屏素材直接生成四宫格与详情长图。需要六张竖图拼图时，在封面版式中选择「竖屏拼图」，默认即为带间隙和取色渐变的 8:9 版式。

已有竖屏拼图历史结果在重新打开时使用新版布局重新渲染；已经下载到电脑的旧图片不会被改动。

更新：设置 → 版本与更新 → 检查更新 → 保存并安装。
