# 帧选 0.3.1 · 修复长图编辑，恢复手动标题

- 4K 角标改为自由开关，不再检查视频分辨率或禁止图片素材使用。封面和详情图都可以单独开启、关闭。
- 修复长图无法编辑：旧编辑逻辑引用了已删除的布局函数，导致所有编辑热区为空。现在编辑热区与实际渲染共用同一套布局，混合横竖图、缩放和长图底部也能准确定位。
- 修复全屏长图拖拽：统一使用指针事件，与封面相同；支持点击替换、图库替换、交换和撤销，编辑后及时更新预览与导出图片。
- 恢复每张详情长图的手动标题输入框。默认由用户填写，无需 AI；留空不显示，可独立关闭显示。标题自动写入图片，并保存在历史记录中。
- 标题输入采用延迟重绘，避免每个按键重复生成；更新过程中暂缓导出，完成后滚动到长图顶部，方便核对标题效果。
- 修复历史恢复时强制关闭标题，以及从长图切换到封面全屏预览后编辑网格显示模式不正确的问题。

## 更新方式

已安装 0.2.0 或更新版本：设置 → 版本与更新 → 检查更新 → 保存并安装。

0.1.6 及更早版本需手动安装新版一次。新版沿用现有应用标识与更新签名公钥。
