## 问题与修复

角标 PNG 是一张包含透明留白的完整叠加图，图案位于右上角。0.3.1 将整张 PNG 缩小到输出宽度的 22% 并画在左上方，实际图案随之缩小和偏移。旧检查只证明画布有像素变化，未核对角标的位置和可见大小。

0.3.2 按输出宽度等比绘制叠加图，维持右上角定位，长图不拉伸角标。角标未成功加载时会报错；图片未更新成功时保留待更新状态，阻止下载旧画布。

## 更新与验证边界

设置 → 版本与更新 → 检查更新 → 保存并安装。更新后打开历史任务，会重新合成包含角标的图片，无需重新分析素材；已下载到电脑的旧图片需要重新下载。

0.2.0 及更新版本支持应用内更新，0.1.6 及更早版本需手动安装一次。更新通道已发布，不代表用户电脑已经安装。
