## 功能验证

1. 68 项 JavaScript 测试和 8 项 Windows Rust 测试通过。
2. 全部失败后自动打开结果页，错误原因可见，重试全部失败按钮可用。
3. 单任务重试期间可追加其他失败任务；重复任务不重复排队，已完成结果不重做。
4. 全部停止后可继续未完成任务，反复停止、重试、暂停恢复不留下运行锁。
5. 本轮、累计、任务、步骤计时推进；暂停冻结，两次运行之间的空闲等待不计入用时；任务累计耗时随历史恢复。

7. 标题条高度、字号、单行/两行、对齐、自动高度影响实际画布像素，长文本不拉伸、不越出条带。
8. 标题参数支持撤销、重做、历史恢复；批量应用保留各图标题，保存默认不改写旧历史。
9. Windows Chromium 验证默认样式刷新后保留、修改其他参数不会覆盖、新任务全部详情继承、显式恢复系统默认有效。

11. 1280/1440/1920 桌面进度截图无横向溢出。原有视频/图片文件夹、长图替换交换、裁剪、角标、拼图、ZIP、历史流程回归通过；未调用付费 AI。
