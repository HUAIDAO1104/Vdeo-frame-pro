## 升级方式和验证边界

0.1.6 及更早版本没有更新模块，本次必须先关闭旧程序，再手动安装 0.2.0。Windows 安装名称、应用标识及数据目录保持旧版兼容配置；CI 检查的是全新安装，没有把旧版覆盖安装描述为已完成实测。

0.2.0 起使用固定 HTTPS 更新清单与签名公钥。启动时及运行期间每 6 小时检查，也可在设置中手动检查。后续发布更高版本并保留同一签名密钥后，用户可收到提示，点击“保存并安装”。任务运行或暂停时禁止安装；停止任务后保存当前工作再继续。

此次验证了最终安装包签名、公开清单、安装启动及模拟更新交互；尚未进行真实 Windows 设备上的跨版本升级验收，也未覆盖不同显卡的长视频负载。此版本没有 Windows Authenticode 发布者证书，更新签名用于应用内校验。
