## 更新与使用

设置 → 版本与更新 → 检查更新 → 保存并安装。打开生成结果或历史任务，封面选择「16:9」→「调整裁剪」→ 拖动或缩放 → 应用 → 下载。四宫格可切换格子分别取景；已有结果无需重新抽帧或评分。

用户截图中的失败发生在 AI 评分阶段，抽帧已完成；本次没有用户原始视频或其 Windows 网络环境，未复现其具体断连原因，不能据此断言是视频宽高比造成。原生通道减少浏览器跨域限制的影响，并提供可操作的故障信息。

交互测试在 Chromium 中完成；Windows 另行验证原生模块、安装和启动，未将这些用例描述为 Windows WebView 实机操作。更新通道开放不代表用户电脑已安装。仓库下载入口更新不代表另行部署 Cloudflare 网站；发布后的说明提交不改变发行标签或安装包。
