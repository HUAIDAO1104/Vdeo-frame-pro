## 使用方式与边界

每张详情长图下方可填写手动标题，留空不显示，也可独立开关标题。点击图片格子替换素材，打开大图后可拖拽交换。4K 角标不再检查素材类型或分辨率，封面和详情图均可自由开关。

0.2.0 及更新版本可在设置 → 版本与更新 → 检查更新后保存并安装；运行中的任务需先等待完成或停止。0.1.6 及更早版本需手动安装新版一次。此次验证包括旧版公钥兼容、公开更新清单、Windows 全新安装与启动，不代表用户实际电脑已完成覆盖升级。

本地浏览器操作验证使用 macOS Chromium 与模拟原生桥接；Windows 上验证了原生模块及安装启动，未将完整浏览器交互用例描述为 Windows WebView 实机测试。仓库下载入口更新不代表另行部署了 Cloudflare 网站。
