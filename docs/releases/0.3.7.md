# 帧选 0.3.7 · 批量重试、实时进度与标题条调节

- 新增「重试全部失败」，已完成任务不会重做。一个任务重试期间，可继续将其他失败任务加入队列，同一任务自动去重。
- 停止全部后可「继续全部未完成」，保留已有图片；支持反复停止、继续、失败后重试。
- 队列结束时，如果仍在素材页，自动打开结果页；即使全部失败也能看到原因并发起重试。正在查看其他结果时不会强制切换。
- 共用进度区显示当前任务、具体步骤、AI 评分批次。Windows 提取画面时每秒报告已提取张数、硬件加速或 CPU 解码。
- 明显显示本轮用时、累计总用时、当前任务用时和当前步骤用时。暂停冻结计时，重试累计，任务耗时随历史保存。显示距离最近反馈的时间及超时上限，不伪造模型内部进度。
- 长图红色标题条新增高度、字号、单行自适应或最多两行、左中右对齐及自动高度。长文字缩小适配，不横向拉伸。所有设置写入实际导出图片，支持撤销、重做和历史恢复。
- 标题条参数可「保存为默认」，重启保留，之后所有新任务使用保存的样式；队列中尚未开始的任务也会使用新默认。可一键应用到本项目全部详情，只复制样式、不覆盖各图标题，支持撤销。

## 更新方式

设置 → 版本与更新 → 检查更新 → 保存并安装。安装前需要停止队列。

也可关闭旧程序后运行本版本 Windows x64 安装包，无需预先卸载。保留当前应用标识、历史数据目录与更新签名公钥。
