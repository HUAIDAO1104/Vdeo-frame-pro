# 帧选 0.2.0 · Windows x64

本版将工作流集中到视频封面与详情图制作。

- 删除文档上传匹配、标题、简介、关键词与销售文案生成。
- 支持运行中移除视频、暂停、继续和停止；保留已完成结果。
- 每个视频完成后立即查看、编辑和导出，无需等待整批。
- 换图、裁剪、交换、撤销和重做自动更新图片，修复历史恢复。
- 简化页面和设置，替换全新图标；默认本地选图，可选 AI 评分。
- 新增启动时及运行期间检查更新、设置中手动检查、保存任务后一键下载安装。

## 从旧版升级

**0.1.6 及更早版本没有自动更新模块。本次需要下载安装一次，之后应用即可接收新版提示。**

下载 `SalesKitStudio_0.2.0_x64-setup.exe`，先关闭旧程序，再运行安装包。无需先卸载。安装名称继续使用“光厂上架助手”，以兼容旧版安装位置；应用内使用“帧选”名称和新图标，保留原应用数据目录。

后续检测到新版本时，点击“保存并安装”。运行或暂停中的任务需先停止；应用会保存当前历史、验证更新签名，然后关闭并在安装完成后重新打开。网络不可用时可继续正常制作图片，稍后在设置中重试。

## 文件

- `.exe`：Windows 10/11 x64 安装包，内置 FFmpeg / ffprobe。
- `.exe.sha256`：安装包 SHA-256。
- `.exe.sig`：应用自动更新签名。
- `latest.json`：自动更新版本清单。
- `build-info.json`：版本、代码提交和构建编号。

更新签名用于应用验证安装包来源；此版本未使用 Windows Authenticode 发布者证书签名。
