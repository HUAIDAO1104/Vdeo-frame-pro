# 帧选 0.3.5 · 六张竖图与自由拼图

- 新增「竖屏拼图」模式：默认 6 张、3 列 × 2 行，整体 27:32，适合六张标准 9:16 竖图。
- 张数可调 1–12，每行可调 1–6 列；末行不足时自动铺满，不额外添加空格或占位图片。
- 单图、四宫格与自由拼图均支持整体比例选择：按原图拼接、27:32、3:4、8:9、1:1、4:3、16:9、9:16 及自定义。
- 自定义宽高支持 1–100 的整数，比值范围为 1:6 至 6:1。整体比例与逐格裁剪分别控制，预览、全屏编辑及导出共用布局计算。
- 选择竖屏拼图后默认不生成详情长图；如需长图，可勾选「同时生成详情长图」。只生成封面时可正常完成、恢复历史和导出 ZIP。
- 不同版式和拼图尺寸分别保留图片及裁剪，支持替换、拖拽交换、撤销重做、4K 角标、下载与历史恢复。
- 自动选图优先补足不同画面，避免候选分组较小时在同一封面过早复用图片。

## 使用方式

添加视频或图片文件夹 → 封面版式选择「竖屏拼图」→ 调整张数、列数和整体比例 → 开始生成。

已有四宫格结果：点击「自由拼图」即可改为六张竖图，无需重新分析；已生成的其他图片会保留。

参考图外框接近 8:9；六张标准 9:16 竖图按 3×2 紧密排列的准确比例为 27:32。需要 3:4 时直接选择对应预设，再按需要逐格调整裁剪。

更新：设置 → 版本与更新 → 检查更新 → 保存并安装。
