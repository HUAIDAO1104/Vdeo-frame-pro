## 比例与使用

参考截图外框约 8:9；六张标准 9:16 竖图无间隔按 3×2 排列的精确比例为 27:32，而非 3:4。27:32、8:9 与 3:4 均有预设，比例指整体成图。选择「按原图拼接」时，整体比例随原图与行列变化；未铺满的末行会改变该行单格比例。

新任务：选择「竖屏拼图」→ 调整张数、列数与整体比例 → 生成。已有结果：点击「自由拼图」即可转换，保留既有详情图片；生成新任务时该模式默认不生成详情。

更新：设置 → 版本与更新 → 检查更新 → 保存并安装。更新通道开放不代表用户电脑已安装。交互测试在 Chromium 中完成；Windows 另行检查原生模块、安装和启动，未将其描述为 Windows WebView 实机交互。仓库下载入口更新不代表另行部署 Cloudflare 网站；发布后的说明提交不改变发行标签或安装包。
