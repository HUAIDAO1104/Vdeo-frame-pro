# 帧选 0.3.2 · 修复下载图片的 4K 角标

- 修复角标素材缩放错误：原素材包含透明留白，上一版错误地缩小整张素材，导致真正的 4K 图案太小并偏离右上角。现在按输出宽度等比叠加，封面和详情长图均在右上角正确显示。
- 预览、单张下载和 ZIP 导出使用同一张合成图片，PNG、JPEG、WebP 以及 0.5×、1×、2× 导出均保留角标。
- 角标未加载时明确提示错误；图片未更新成功前阻止下载旧图，避免开关已选中但文件不含角标。
- 增加对真实下载图片的像素验证，并加入 Windows 发布检查。

## 更新方式

设置 → 版本与更新 → 检查更新 → 保存并安装。

打开原来的历史任务后，会按新的角标布局重新生成图片；无需重新分析素材。0.1.6 及更早版本需手动安装新版一次。
