# 帧选 0.3.0 · 图片文件夹

- 新增「选择图片文件夹」：每个文件夹作为一个独立任务，可和视频一起排队，包含子文件夹内的 JPG、JPEG、PNG、WebP。
- 直接分析图片，不经过视频截帧，不受截帧间隔、时间范围或候选帧数量设置限制。按文件名自然排序，保留名称供查看、替换和下载。
- 图片按画面相似度归并，不套用视频时间窗口；不同宽高比的图片分别保留。所有代表图片都参与本地或 AI 评分，没有固定 32 张上限。
- 支持暂停、继续、停止、运行中移除、逐任务查看结果，以及替换、裁剪、导出图片包和历史恢复。
- Windows 会将导入图片复制到应用本地缓存，原文件移动后仍可恢复历史。浏览器历史在本机保存导入文件。不会修改或删除原文件。
- 单张图片最多 24 MB；空文件、超限和损坏图片会提示跳过原因。其他格式不导入。全部图片无效时任务报错，不生成空结果。
- 素材页自动区分视频预览与图片文件夹，图片任务隐藏视频截帧设置；混合队列和窄屏布局同步适配。

## 更新

已安装 0.2.0 或更新版本：设置 → 版本与更新 → 检查更新 → 保存并安装。安装前需先停止运行中的任务。

0.1.6 及更早版本需要手动下载安装包升级一次。安装包延续原安装标识与更新签名公钥。
