## 使用方式与边界

素材页 → 选择图片文件夹 → 开始生成。支持 JPG/JPEG、PNG、WebP，包含子目录，单张最多 24 MB；其他格式不导入。图片不使用视频截帧时间或数量设置。图片相似度基于空间颜色和构图近似比较，且区分宽高比，仍保留全部有效候选供手动替换。

Windows 图片副本保存在应用缓存；网页版保存导入文件和候选到本机 IndexedDB。文件夹初次复制发生在分析任务开始前，暂停和停止控制的是后续分析、评分与合成流程。

0.2.0 及更新版本可在设置中检查更新并“保存并安装”；正在导入素材、运行/暂停任务或编辑图片时需先等待或停止。0.1.6 及更早版本需手动安装新版一次。此次验证包括旧版公钥兼容、公开更新清单、Windows 全新安装与启动，不代表用户实际电脑已完成覆盖升级。
