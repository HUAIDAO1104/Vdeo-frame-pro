# 帧选 0.2.1 · Windows x64

本版优化视频选图：根据画面变化挑选代表帧，减少重复评分，同时移除固定 32 张 AI 评分限制。

- 相邻且相似的候选归为一组，保留清晰度与曝光综合表现较好的一张。
- 镜头切换、明显构图变化和较大的时间缺口保留新的代表帧；与组内起始画面对照，避免缓慢运镜被一路合并。
- 全部代表帧按每批最多 8 张进行 AI 评分，不再截断为 32 张；自动排序池也不再固定限制为 60 张。
- 自动成图只使用代表帧，原始候选全部保留供手动替换。
- 结果页显示提取、合并与代表帧数量，并随历史保存；保留原始 AI 维度评分及每帧评分来源。
- 代表画面少时采用紧凑详情布局并提示复用；重新仅提取候选时清除旧评分统计。

## 升级

已安装 0.2.0：打开“设置 → 版本与更新 → 检查更新”，停止运行或暂停中的任务，然后点击“保存并安装”。应用也会在启动时及运行期间定时检查。

0.1.6 及更早版本没有更新模块，请先关闭旧程序，再运行 `SalesKitStudio_0.2.1_x64-setup.exe`，无需预先卸载。安装名称继续使用“光厂上架助手”，界面使用“帧选”，沿用原应用标识与数据目录。

## 使用范围

归并依据本地画面相似度，并非语义模型对真实镜头的精确识别，细微动作或表情仍可能被合并。处理基于已提取候选，原有抽帧间隔、模式和最多 600 帧的资源限制保持不变；不能找回未提取的画面。内容变化多的视频可能需要更多评分请求和等待时间。

本版不更换视觉模型，继续使用已配置的千问或兼容接口。

安装包内置 FFmpeg / ffprobe。`.exe.sig` 与 `latest.json` 用于应用更新签名校验，`.exe.sha256` 用于文件完整性校验，`build-info.json` 记录构建来源。此版本未使用 Windows Authenticode 发布者证书签名。
