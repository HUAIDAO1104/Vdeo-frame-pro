## 使用

选择「竖屏拼图」即可生成带间隙、取色渐变和投影的 8:9 封面。生成前或结果卡片内均可统一调整投影大小与距离；张数和每行列数仍可调整。该模式默认关闭详情长图，可手动开启。已有竖屏拼图历史重新打开时使用新版布局渲染，已下载的旧图片不变。

更新：设置 → 版本与更新 → 检查更新 → 保存并安装。发布到更新通道不代表用户电脑已经安装。交互测试使用 Chromium；Windows 另行检查原生模块、安装和启动，没有将其描述为 Windows WebView 实机交互。仓库下载入口更新不代表另行部署 Cloudflare 网站；发布后的说明提交不改变发行标签或安装包。
