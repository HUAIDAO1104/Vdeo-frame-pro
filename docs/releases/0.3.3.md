# 帧选 0.3.3 · 单图封面与 4K 角标

- 每张封面新增「单图 / 四宫格」切换，直接把已有封面改为一张图片，无需重新分析素材。
- 单图支持候选图片替换、裁剪、独立开关 4K 角标、单张下载和 ZIP 导出。
- 两种版式分别保留图片和裁剪，切回四宫格恢复原来的四张图；支持撤销、重做和历史恢复。
- 单图按照所选图片的宽高比输出，横图、竖图、方图均可使用。默认生成尺寸最大边为 3840，不主动放大小图；仍可通过导出倍率调整。
- 封面卡片直接显示 4K 角标，方便下载前确认。超宽图片上的角标等比缩放并靠右上角显示。

## 使用方式

生成结果 → 封面版式选择「单图」→ 点击图片替换需要的画面 → 开启「4K 角标」→ 下载。

更新：设置 → 版本与更新 → 检查更新 → 保存并安装。
